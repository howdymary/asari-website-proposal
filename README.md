# Asari AI — website proposal

[View the public proposal](https://howdymary.github.io/asari-website-proposal/)

An independently prepared website concept with illustrated, scroll-driven scenes. This is a proposal, not the official Asari AI website.

Insights reproduces the original Asari blog index and four complete articles with permission confirmed by the site owner. Original article wording, illustrations, animation components, charts, and video are retained. The article documents are served directly; there is no production iframe.

Asset URLs and internal navigation are adapted for GitHub Pages. Cross-page navigation uses full document loads. Original analytics and server-dependent link prefetch are disabled. No animation component is reimplemented. The source-to-publication manifest is in `original-asari/manifest.json`.

This repository contains only the published static website. GitHub Pages serves the main branch.
