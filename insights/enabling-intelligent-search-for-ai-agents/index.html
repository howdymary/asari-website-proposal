EnCompass: search without workflow rewrites

A research framework for exploring alternative agent execution paths.

December 4, 2025Original publication: Zhening Li and collaborators at Asari AI
NeurIPS 2025EnCompass research publicationRead the full article

A summary of the linked Asari publication. The original includes the complete experiments, figures, and technical discussion.

The core idea

Workflow code marks decision points and evaluations. EnCompass manages alternative executions, allowing developers to change search strategies without rebuilding the agent’s task logic.

What was evaluated

The Asari–MIT work compares search strategies on tasks including code translation. Its case studies required three to six times fewer code changes than hand-built Python search implementations.

Where it fits

EnCompass makes multi-step agents easier to experiment with. Inference-time search here means exploring reasoning paths; it is distinct from accelerating GPU model serving.
